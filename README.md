# 🍳 Проект рецепты

Небольшой учебный проект на Next.js для изечения фреймворка и практики

## 🚀 Технологии

- Next.js
- React
- Typescript
- Остальные буду добавльять по мере необходимости

## 📋 Возможности

- [ ] Просмотр списка рецептов
- [ ] Просмотр подробной информации о рецепте
- [ ] Поиск рецептов
- [ ] Фильтрация по категориям

## 🛠️ Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
